# Nothing Landing Page — Modern Tech Store Website

This project is a modern, responsive landing page for the **Nothing** tech brand. It showcases featured tech products, product categories, brand information, and an interactive contact form, offering a clean, user-friendly shopping experience using BEM methodology.

## Live Preview

Experience the live website: [Click here to view the Live Demo](https://chempik120.github.io/Landing-Page/)

## Design Reference

* **Figma Design:** You can check the design layout via [Figma Concept Design](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6802-139&p=f&t=oSiMQMCp2DBnZad9-0)

## Technologies Used

### Core

* **HTML5** – Semantic structure
* **CSS3 / SCSS** – Styling and layout with BEM methodology
* **JavaScript (ES6+)** – Interactive UI components (navigation menu, contact form logic)

### Fonts & Assets

* **Google Fonts** – Typography powered by [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) and [Space Mono](https://fonts.google.com/specimen/Space+Mono)
* **Assets** – Vector icons and high-quality product images

## Key Features

* **Responsive Design:** Fully responsive layout optimized for mobile, tablet, and desktop screens.
* **Navigation Menu:** Mobile overlay drawer menu with fast anchor navigation to sections.
* **Recommended Products:** Dynamic product showcase for flagship devices (Phone (1), Ear (2), Ear (stick)).
* **Category Browsing:** Visual product categories leading to specialized store sections.
* **Contact Form:** Interactive form with client-side validation and automatic form resetting upon submission.

## Getting Started

Follow these simple steps to set up and launch the project on your local machine:

### 1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Install dependencies:

```bash
npm install
```

### 3. Run the project locally:

```bash
npm start
# or
yarn start
```

*Or simply open `index.html` directly in your browser of choice.*
